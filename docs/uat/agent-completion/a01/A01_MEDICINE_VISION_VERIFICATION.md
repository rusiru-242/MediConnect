For: the project owner, pharmacist reviewers and engineers. 2026-11-26, branch `fix/agents-a01-ai-intelligence-vision`.

## Pipeline (verified end to end)

```mermaid
flowchart LR
  P[Flutter: file picker\njpg/png, 5 MB check] --> PV[Preview + remove]
  PV --> U[POST /ai/booking/sessions/:id/image\nJWT, owner check, rate limit]
  U --> VAL[read ≤ 5 MB + 1 byte\nextension + magic bytes]
  VAL --> LLM[llm_client: primary → secondary\nreal bytes inline, strict schema]
  LLM --> CHK[pydantic VisionExtraction\nquality / loose / multiple / injection / dosing rules]
  CHK --> OUT[reply text + structured card\nprovider + model shown]
  LLM -- all failed --> UN[provider_unavailable:\n"I have not read anything from your photo"]
```

## Output rules

| Rule | How it is enforced |
|---|---|
| Report only what is visible | Separate fields: brand vs generic name, active ingredient, strength, form, route, category, manufacturer, expiry, printed storage directions, and fields present but unreadable |
| Visible text vs reference information vs uncertain | Reply sections: "Text read from your photo (as printed — not verified)", "Reference information from the MediConnect medicine library", "Not readable in this photo: …" |
| No invented values | Empty or null fields are omitted. A photo the model itself rates `blurry` or `dark` is never presented as read (A01-N09). |
| No prescription or personal dose | Printed dosing directions are detected and not repeated. "The strength on a package is not a dose recommendation." |
| No identity from loose tablets | `loose_tablets_only` → no name, ever, even if the model returns one |
| Several packages | `multiple_packages` status, no single library card, ask for one package at a time (A01-N14) |
| No numeric confidence | Status-based badge only. The "High Confidence" badge was removed. |
| Pharmacist confirmation | Every result: "Check the package with a registered pharmacist or your doctor before use." |
| Embedded instructions | The prompt says image text is data. Strings that look like instructions to an AI are dropped and flagged (`embeddedTextIgnored`). |

## Fixtures and expected values

Fixtures are in `backend/tests/fixtures/a01_vision/`, generated by `make_vision_fixtures.py`. All are fictional products: Synthopar 500, Synthomox 250, Synthocet 10, all by "Synthetic Test Labs Ltd".

The expected visible values were written to `expected_labels.json` **before** any provider read the images.

## Limitations

- **Rendered images only.** The fixtures are synthetic: flat, well lit and printed in Arial. Real photographed packaging (glare, curvature, Sinhala or Tamil print, blister foil) has not been tested.
- **Model variance.** The same image gave "Synthopar 500" in one run and "Synthopar" in another.
- **O2:** the model sometimes lists absent fields as "not readable". The prompt was tightened but not re-tested live.
- **No camera capture** in the app; there was no physical-device test (B10).
- **Owner gates before real patients:** a data-processing agreement for images (B13) and pharmacist review of the library text (B2).
